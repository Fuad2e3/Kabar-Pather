## ২. স্বয়ংক্রিয় .webp ফটো অপ্টিমাইজেশন পাইপলাইন (Photo Optimization Pipeline)

ওয়েবসাইটের পারফরম্যান্স ও পেজ লোডিং স্পিড সর্বোচ্চ রাখতে ইমেজ অপ্টিমাইজেশন সিস্টেম তৈরি করা হয়েছে:

### ক্লায়েন্ট স্তর (`assets/js/optimization.js`):
- যেকোনো ফরম্যাটের ছবি (JPG, PNG, JPEG, WEBP) ব্যবহারকারী সিলেক্ট করলে তা স্বয়ংক্রিয়ভাবে `PhotoOptimizer.optimize(file)` মেথডের মধ্য দিয়ে যায়।
- HTML5 Canvas ব্যবহার করে ছবির ডাইমেনশন স্কেল করা হয় (সর্বোচ্চ ৯৬০px প্রস্থ ও উচ্চতা)।
- স্বচ্ছ PNG ইমেজের ক্ষেত্রে ব্যাকগ্রাউন্ড স্বয়ংক্রিয়ভাবে ক্লিন হোয়াইট ফিলাপ হয়।
- আউটপুট ফরম্যাট হিসেবে এনকোড করা হয় `image/webp` (কোয়ালিটি ০.৮২)।
- **ফলাফল:** ৪MB – ১০MB সাইজের ছবি কোনো ভিজ্যুয়াল কোয়ালিটি লস ছাড়াই মাত্র **৪০KB – ৮০KB** তে নেমে আসে (৮৫%–৯৫% ফাইল সাইজ সাশ্রয়)।

### সার্ভার স্তর (`functions/api/_api.js`):
- `/api/upload` এন্ডপয়েন্টে পাঠানো ফাইলটি সবসময় `.webp` এক্সটেনশনসহ সুরক্ষিত অবজেক্ট স্টোরেজে সংরক্ষিত হয়।
- পাবলিক সার্ভিং হেডার `Cache-Control: public, max-age=31536000, immutable` প্রদান করে যাতে পরবর্তী সময়ে ছবিগুলো ইনস্ট্যান্টলি লোড হয়।

## ৩. ব্যাকএন্ড এন্ডপয়েন্ট রেফারেন্স (Edge REST API)

### 🛍️ পণ্য (Products):
- `GET /api/products` — সকল সক্রিয় ও নিষ্ক্রিয় পণ্যের তালিকা রিটার্ন করে।
- `POST /api/products` — নতুন পণ্য যুক্ত অথবা বিদ্যমান পণ্য আপডেট করে।
- `DELETE /api/products/:id` — নির্দিষ্ট পণ্য ডাটাবেস থেকে মুছে ফেলে।
- `POST /api/products/seed` — প্রারম্ভিক পণ্য ক্যাটালগ রিস্টোর/সিড করে।

### 📦 অর্ডার (Orders):
- `GET /api/orders` — সকল গ্রাহক অর্ডারের তালিকা (এডমিনের জন্য)।
- `POST /api/orders` — নতুন অর্ডার গ্রহণ করে, স্টক ডিক্রিমেন্ট করে এবং অর্ডার আইডি রিটার্ন করে।
- `POST /api/orders/status` — অর্ডারের স্ট্যাটাস আপডেট করে (`Pending`, `Confirmed`, `Delivered`, `Cancelled`)।
- `GET /api/orders/track?phone=...&ref=...` — গ্রাহকের নিজস্ব অর্ডার ট্র্যাকিং ডাটা।

### 👥 গ্রাহক ও ইউজার (Users & Auth):
- `POST /api/users/register` — নতুন গ্রাহক রেজিস্ট্রেশন।
- `POST /api/users/login` — গ্রাহক লগইন ও ক্রেডেনশিয়াল ভেরিফিকেশন।
- `GET /api/users` — নিবন্ধিত সকল গ্রাহকের তালিকা।
- `POST /api/users/status` — গ্রাহক একাউন্ট সক্রিয় বা স্থগিত (Suspend) করা।

### 🖼️ ছবি আপলোড (Photo Upload):
- `POST /api/upload` — `.webp` ইমেজ আপলোড এন্ডপয়েন্ট (JSON Base64 অথবা Multipart Form-Data)।
- `GET /api/images/:key` — এজ স্টোরেজ থেকে সরাসরি ক্যাশড ইমেজ রিটার্ন করে।

## ৪. এডমিন প্যানেল গাইডলাইন (Admin Panel Walkthrough)

- **অ্যাক্সেস URL:** ব্রাউজারে `admin.html` ফাইল ওপেন করুন।
- **ডিফল্ট লগইন:**
  - ইমেইল: `admin@kabarpather.com`
  - পাসওয়ার্ড: `admin123`
  - *(অথবা এক ক্লিকে "এডমিনে প্রবেশ করুন" বাটনে চাপুন)*

### নতুন বিক্রয় পোস্ট করা:
1. "➕ নতুন পণ্য যোগ / পোস্ট" ট্যাবে যান।
2. পণ্যের নাম, ক্যাটাগরি, বিক্রয় মূল্য, মজুদ সংখ্যা পূরণ করুন।
3. অন্তর্ভুক্ত সামগ্রী প্রতি লাইনে একটি করে লিখুন।
4. "📁 ছবি আপলোড" বাটনে চাপ দিয়ে যেকোনো ছবি সিলেক্ট করুন — এটি স্বয়ংক্রিয়ভাবে `.webp` তে অপ্টিমাইজ হয়ে যাবে।
5. ডানপাশের লাইভ প্রিভিউ কার্ডে দেখে নিন কার্ডটি কেমন দেখাবে।
6. "✓ পণ্য প্রকাশ করুন" বাটনে চাপ দিলে পণ্য সরাসরি ডাটাবেসে সেভ হয়ে ওয়েবসাইটে লাইভ চলে আসবে।

## ৫. ডিপ্লয়মেন্ট কমান্ডস (Edge Deployment Guide)

```bash
# ১. এজ D1 ডাটাবেস তৈরি করুন:
npm run db:create
# (প্রাপ্ত database_id টি wrangler.toml ফাইলের database_id এ পেস্ট করুন)

# ২. এজ R2 অবজেক্ট স্টোরেজ বাকেট তৈরি করুন:
npm run r2:create

# ৩. ডাটাবেস স্কিমা ও পণ্যসমূহ ইনিশিয়ালাইজ করুন:
npm run db:init
npm run db:seed

# ৪. লাইভ এজ প্ল্যাটফর্মে ডিপ্লয় করুন:
npm run deploy
```

## ৬. অফলাইন / লোকাল সাপোর্ট (Offline Resilience)

যদি ইন্টারনেট কানেকশন বা এজ সার্ভার সাময়িকভাবে অনুপস্থিত থাকে, `assets/js/api-client.js` স্বয়ংক্রিয়ভাবে ব্রাউজারের `localStorage` ব্যবহার করে:
- পণ্য ক্যাটালগ লোকাল ক্যাশ থেকে প্রদর্শিত হয়।
- কার্ট ও চেকআউট লোকালভাবে সম্পন্ন হয়।
- এডমিন প্যানেল অফলাইনেও পণ্য অ্যাড ও এডিট প্রিভিউ সাপোর্ট করে।
- পুনরায় সার্ভার কানেক্ট হলে ডাটাবেসের সাথে সিঙ্ক হয়ে যায়।
