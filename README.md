# কবর পথের সামগ্রী (Kabar Pather Samogri)

> **সম্মান, যত্ন ও নির্ভরযোগ্য সেবা**  
> দাফন ও জানাজা-সংক্রান্ত সকল প্রয়োজনীয় সামগ্রী সহজে, দ্রুত ও নির্ভরযোগ্যভাবে সংগ্রহ করুন।

---

## 📖 প্রজেক্ট পরিচিতি (About)

**কবর পথের সামগ্রী** হলো একটি আধুনিক ও সংবেদনশীল ল্যান্ডিং পেজ ওয়েবসাইট, যা প্রয়োজনের সময়ে মানুষের পাশে দাঁড়ানোর উদ্দেশ্যে নির্মিত। এতে দাফন ও জানাজা সংক্রান্ত সমস্ত প্রয়োজনীয় সামগ্রীর বিশদ বিবরণ, প্যাকেজ ইনফো এবং সরাসরি দ্রুত যোগাযোগের সুযোগ (কল ও হোয়াটসঅ্যাপ) রাখা হয়েছে।

---

## 🎨 ডিজাইন স্পেসিফিকেশন

- **কালার থিম:** রয়েল ল্যাভেন্ডার ও ডিপ পার্পল (`#451970`)
- **টাইপোগ্রাফি:** 
  - বাংলা: **Hind Siliguri** (Google Fonts)
  - সংখ্যা ও ইংরেজি: **Plus Jakarta Sans** (Google Fonts)
- **লেআউট:** ১০০% রেসপন্সিভ (মোবাইল, ট্যাবলেট এবং ডেস্কটপ ফ্রেন্ডলি)
- **ইন্টারঅ্যাক্টিভ ফিচার:**
  - প্রতিটি পণ্যের বিস্তারিত বিবরণী সমৃদ্ধ ডায়লগ মোডাল (Modal Dialog)
  - ১-ক্লিকে হোয়াটসঅ্যাপ অর্ডার বার্তা প্রেরণের লিঙ্ক
  - সার্বক্ষণিক দ্রুত যোগাযোগের জন্য ফ্লোটিং অ্যাকশন বাটন (Call & WhatsApp)
  - স্মুথ স্ক্রোল নেভিগেশন ও স্ক্রলস্পাই

## 📦 অন্তর্ভুক্ত সেকশনসমূহ

1. **টপ হেডার ও ব্র্যান্ডিং:** লোগো, স্লোগান, নেভিগেশন মেনু এবং হটলাইন কল বাটন (`01844-687759`)।
2. **হিরো সেকশন:** প্রধান শিরোনাম `প্রয়োজনের সময়ে আপনার পাশে`, অ্যাকশন বাটন এবং ৩টি মূল প্রতিশ্রুতি (দ্রুত ডেলিভারি, বিশ্বস্ত সেবা, সব সামগ্রী এক জায়গায়)।
3. **আমাদের পণ্য (`❖ আমাদের পণ্য ❖`):**
   - কাফনের কাপড়
   - দাফনের প্রয়োজনীয় সামগ্রী
   - জানাজার সামগ্রী
   - অন্যান্য প্রয়োজনীয় পণ্য
4. **বিশ্বস্ততা ও তাৎক্ষণিক অর্ডার ব্যানার:** ইসলামিক খিলান আর্চে কাবা শরীফ ও শুভ্র ইহরামের দৃশ্য, ৪টি সেবামূলক বৈশিষ্ট্য এবং অর্ডার ব্যানার।
5. **কীভাবে অর্ডার করবেন? (৪টি সহজ ধাপ):** পণ্য নির্বাচন ➔ যোগাযোগ ➔ কনফার্মেশন ➔ ডেলিভারি গ্রহণ।
6. **ফুটার:** সম্পূর্ণ ঠিকানা (কামরাঙ্গীরচর, ঢাকা), হটলাইন নম্বর, ২৪ ঘণ্টা সেবার বিবরণী এবং সোশ্যাল মিডিয়া।

## 🚀 কীভাবে চালাবেন (How to Run Locally)

কোনো অতিরিক্ত ডিপেন্ডেন্সি প্রয়োজন নেই। সাধারণ যেকোনো ব্রাউজারে `index.html` ফাইলটি ওপেন করলেই চলবে:

```bash
# অথবা পাইথন দিয়ে লোকাল সার্ভারে চালাতে পারেন:
python -m http.server 8080
```

এরপর ব্রাউজারে প্রবেশ করুন: `http://localhost:8080`
