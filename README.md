## 📖 ওভারভিউ (Project Overview)

**কবর পথের সামগ্রী (Kabar Pather Samogri)** হলো একটি বিশেষায়িত ইসলামিক ই-কমার্স ও ২৪/৭ জরুরি সেবা প্ল্যাটফর্ম। শোকাহত পরিবারের কঠিন মুহূর্তে সময় ও মানবিক অনুভূতিকে সর্বোচ্চ অগ্রাধিকার দিয়ে দ্রুততম সময়ে কাফনের কাপড়, সুগন্ধি আতর, সুরমা এবং পূর্ণাঙ্গ দাফন প্যাকেজ সরবরাহ করার উদ্দেশ্যে প্ল্যাটফর্মটি তৈরি করা হয়েছে।

### ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)

- ⚡ **লাইটওয়েট ভ্যানিলা ফ্রন্টএন্ড**: শূন্য ফ্রেমওয়ার্ক ওভারহেড, পিওর ভ্যানিলা ES6+ জাভাস্ক্রিপ্ট ও রেসপন্সিভ সিএসএস।
- 🌓 **অটোনোমাস ডিভাইস অটো দিন/রাত থিম ইঞ্জিন**: ব্যবহারকারীর মোবাইল বা পিসির সিস্টেম সেটিংসের সাথে সম্পূর্ণ স্বয়ংক্রিয় সিঙ্ক (কোনো অপ্রয়োজনীয় ম্যানুয়াল বাটনের ঝামেলা ছাড়াই শতভাগ ক্লিন ও বিভ্রান্তিমুক্ত ইন্টারফেস)।
- 📱 **ফুল রেসপন্সিভ সর্বডিভাইস সাপোর্ট**: আল্ট্রা-কম্প্যাক্ট মোবাইল (<৩৮০px), স্ট্যান্ডার্ড স্মার্টফোন, ট্যাবলেট এবং ডেস্কটপে ত্রুটিহীন লেআউট ও নিরাপদ স্ক্রোলিং।
- 🖼️ **ইন-ব্রাউজার WebP ফটো অপ্টিমাইজার**: HTML5 Canvas ব্যবহার করে স্মার্টফোন দিয়ে তোলা ৪MB–১২MB ছবি স্বয়ংক্রিয়ভাবে ৪০KB–৭০KB `.webp` ফরম্যাটে কম্প্রেস হয় (৮০%–৯৫% ব্যান্ডউইথ সাশ্রয়)।
- 🛒 **স্লাইড-ইন কার্ট ও স্মার্ট ডেলিভারি ক্যালকুলেটর**: ঢাকা সিটি (৳৮০) ও ঢাকার বাইরে (৳১৫০) স্বয়ংক্রিয় ডেলিভারি ফি ক্যালকুলেশন।
- 🛍️ **ইন্টারেক্টিভ প্রোডাক্ট মডাল ও ডুয়েল অ্যাকশন**: প্রোডাক্ট বিস্তারিত পপআপ থেকে সরাসরি ১-ক্লিকে ওয়েবসাইটের মূল "অর্ডার করুন" (চেকআউট ড্রয়ার) এবং "WhatsApp এ অর্ডার করুন" সুবিধা।
- 📦 **রিয়েল-টাইম অর্ডার ট্র্যাকিং ও ১-ট্যাপ হোয়াটসঅ্যাপ**: অর্ডার রেফারেন্স দিয়ে তাৎক্ষণিক ট্র্যাকিং এবং হোয়াটসঅ্যাপে প্রি-ফরম্যাটেড অর্ডার বার্তা।
- 🛡️ **এডমিন ম্যানেজমেন্ট পোর্টাল**: লাইভ কার্ড প্রিভিউসহ সেল পোস্ট ক্রিয়েটর, ইন-প্লেস প্রোডাক্ট এডিটিং, অর্ডার প্রসেসিং ও কাস্টমার একাউন্ট অ্যাক্সেস নিয়ন্ত্রণ।
- 🌐 **সার্ভারলেস এজ আর্কিটেকচার**: এজ D1 রিলেশনাল SQLite ডাটাবেস এবং এজ R2 অবজেক্ট স্টোরেজ ইন্টিগ্রেশন।

## 🚀 লোকাল ডেভেলপমেন্ট ও ভেরিফিকেশন (Getting Started)

### ১. ক্লোন ও ইনস্টলেশন
```bash
git clone https://github.com/Fuad2e3/Kabar-Pather.git
cd Kabar-Pather
npm install
```

### ২. অটোমেটেড টেস্ট পরিচালনা
```bash
npm test
```
*এই কমান্ডটি সমস্ত জাভাস্ক্রিপ্ট সিনট্যাক্স, ডাটাবেস স্কিমা, API এন্ডপয়েন্ট, দিন/রাত কনট্রাস্ট, মোবাইল টাচ-স্ক্রলিং, থিম ইঞ্জিন ও নিরপেক্ষতা নিয়ম পরীক্ষা করে (১৯৪টি টেস্ট)।*

### ৩. লোকাল এজ ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
